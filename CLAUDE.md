# mikholand UI

Дизайн-система: токены → CSS-компоненты `mk-*` → поведение без зависимостей → тонкие React-обёртки.

## Слои и где что править

- `tokens/tokens.json` — единственный источник значений. `dist/tokens.css` и `src/tokens.ts` генерирует `scripts/build-tokens.mjs`, руками их не трогать.
- `src/css/<компонент>.css` — вся визуальная часть. Только токены, никаких литералов цвета. Порядок склейки — `src/css/order.json`.
- `src/core/index.js` — поведение (select, tabs, segmented, menu, popover, pagination, drawer). Ничего не делает при импорте и не трогает `window` до вызова: модуль импортируется при SSR. Типы — рукописные в `src/core/index.d.ts`, обновлять вместе с кодом.
- `src/react/*` — обёртки. Собственных стилей нет: только классы `mk-*` и вызов core через `useCore`. Всплывающие панели рендерятся порталом в body и передаются в core через `panel`, иначе React-события внутри не работают.
- `docs/guidelines.md` и `docs/components/*.md` — правила использования. Меняешь поведение или вид — обнови соответствующий файл.

## Правила системы (коротко)

- Строгий плотный B2B-интерфейс: контролы 34px (`control-height`), карточки без рамок, только `surface` + `shadow-card`.
- Синий только акцент. Никаких синих теней, glow, `translateY`/`scale` на hover, теней у кнопок.
- У secondary-кнопок нет синего ни в одном состоянии. Иконка в кнопке с текстом — справа.
- Текст статусов — токены `*-text` на `*-soft`; контраст ≥ 4.5:1 в обеих темах.
- Страница без горизонтального скролла до 360px; таблицы скроллятся внутри `.mk-table-wrap`.

## Команды

- `npm run check` — типы и сборка. Запускать перед каждым коммитом.
- `npm run preview` — сборка и витрина на http://localhost:3200/preview/.
- Релиз: поднять `version` в package.json и закоммитить в `main`, затем опубликовать GitHub Release с тегом `v<версия>`; workflow `publish.yml` опубликует в npm.
