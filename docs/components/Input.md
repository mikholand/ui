Текстовое поле и многострочный ввод с подписью, подсказкой и состоянием ошибки.

## Разметка

```html
<div class="mk-field">
  <label class="mk-label" for="name">Название канала</label>
  <input class="mk-input" id="name" placeholder="Например, Витрина посуды">
  <span class="mk-hint">Видно покупателям в заголовке витрины.</span>
</div>
```

`textarea` получает тот же класс `mk-input` и минимальную высоту 88px.

## Ошибка

Поставь `aria-invalid="true"` на поле, замени подсказку на `mk-hint mk-hint--error` и свяжи их через `aria-describedby`. Текст ошибки говорит, что исправить: «Введите число, например 1 290».

## Правила

- Подпись всегда видна над полем, плейсхолдер её не заменяет.
- Focus красит рамку в `accent`, hover рамку не меняет.
- Поля в форме идут в одну колонку с зазором `space-4`; на desktop допустимы две колонки для коротких полей.
- `disabled` — для полей, которые нельзя менять сейчас; почему, объясни в подсказке.
