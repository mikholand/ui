KPI-карточка: подпись, крупное значение и сравнение с прошлым периодом.

## Разметка

```html
<div class="mk-kpi-grid">
  <div class="mk-kpi">
    <span class="mk-kpi__label">Выручка за неделю</span>
    <span class="mk-kpi__value">184 320 ₽</span>
    <span class="mk-kpi__meta"><span class="mk-kpi__delta mk-kpi__delta--up">+12,4%</span>к прошлой неделе</span>
  </div>
</div>
```

`mk-kpi-grid` раскладывает карточки автоматически: колонки не уже 180px.


## React

```tsx
import { Kpi, KpiGrid } from "@mikholand/ui/react";

<KpiGrid>
  <Kpi label="Выручка за неделю" value="184 320 ₽" delta="+12,4%" trend="up" meta="к прошлой неделе" />
  <Kpi label="Средний чек" value="1 646 ₽" delta="−3,1%" trend="down" meta="к прошлой неделе" />
</KpiGrid>
```

`trend` выбирается по смыслу (хорошо или плохо), а не по знаку дельты. Числа форматирует приложение.

## Правила

- Значение — цифры с неразрывным пробелом в тысячах, валюта после числа: `184 320 ₽`. Отрицательная дельта — с настоящим минусом «−».
- Рост — `mk-kpi__delta--up`, падение — `mk-kpi__delta--down`. Если рост плохой (например, отмены), выбирай модификатор по смыслу, а не по знаку.
- Подпись говорит, с чем сравнение: «к прошлой неделе».
- 3–5 KPI в ряд. Больше — значит, это таблица, а не KPI.
- KPI не должны занимать первый экран целиком: главный рабочий объект важнее.
