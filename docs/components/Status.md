Статус-пилюля объекта: заказа, задачи, оплаты. Цвет всегда идёт вместе со словом.

## Разметка

```html
<span class="mk-status mk-status--success"><span class="mk-status__dot"></span>Оплачен</span>
<span class="mk-status">Черновик</span>
```


## React

```tsx
import { Status } from "@mikholand/ui/react";

<Status tone="success" dot>Оплачен</Status>
<Status tone="process">В сборке</Status>
<Status>Черновик</Status>
```

`tone`: `success`, `warning`, `danger`, `process`, `neutral` по умолчанию; `dot` добавляет точку.

## Варианты

| Класс | Смысл |
| --- | --- |
| `mk-status--success` | Готово, оплачено, доставлено. |
| `mk-status--process` | В работе, в сборке, синхронизируется. |
| `mk-status--warning` | Требует внимания: ждёт оплаты, мало на складе. |
| `mk-status--danger` | Ошибка, отмена, просрочено. |
| без модификатора | Нейтральное: черновик, архив. |

## Правила

- Текст статуса — `*-text` на подложке `*-soft`, контраст не ниже 4.5:1 в обеих темах.
- Одно-два слова, с заглавной буквы, без точки.
- Точка `mk-status__dot` опциональна: ставь её в плотных таблицах, где статус надо найти взглядом.
- Не делай все статусы синими: «в процессе» — единственный синий статус.
